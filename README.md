# Discovery 2K26

Discovery 2K26 is ADCET, Ashta's national-level technical festival website and registration portal.

The site gives students one place to explore the festival, browse department-wise events, read event descriptions and rules, download paper-presentation resources, and register individuals or teams for competitions.

## What The Website Includes

- A bold neo-brutalist festival homepage with the Discovery 2K26 identity
- Department-wise event discovery and filtering
- Detailed event pages with topics, rules, specifications, coordinators, dates, and downloadable resources
- Responsive registration forms for solo participants and teams
- Dynamic team-size selection and registration fee breakdowns
- Razorpay payment flow for registration checkout
- Registration processing with duplicate-request protection and queue monitoring
- Administrative tools for registration and queue management
- Confirmation email support for completed registrations

## Festival Experience

The interface is designed for fast browsing on phones and desktops. High-contrast typography, strong borders, yellow and pink accents, structured event information, and direct registration actions make the festival schedule easy to scan and use.

## Technology

- React and TypeScript
- Vite
- React Router
- Tailwind CSS and shadcn/ui
- Express and TypeScript backend
- MongoDB with Mongoose
- Razorpay payments

## Project Areas

- `frontend/` contains the public website and registration experience.
- `backend/` contains the registration API, payment verification, email delivery, queues, monitoring, and administrative endpoints.
- `frontend/public/` contains static files such as event images, robots.txt, and downloadable event documents.

Discovery 2K26 brings the festival schedule, event information, and registration workflow together for ADCET, Ashta.
